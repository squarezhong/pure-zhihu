# Pure Zhihu

从问答平台到社交媒体（不带任何推荐算法的那种）。

## 简介

知乎网页端简化脚本：

- 默认从首页进入关注流
- 在全站移除“关注”栏之外的顶栏噪音
- 移除“知乎直答”按钮
- 侧边栏移除“大家都在搜”和“盐言作者平台”
- 两种模式均过滤信息流、侧栏和回答页的显式广告（含异步加载的广告）。

### 模式

- 扩散模式：默认
- 严格模式：在扩散模式的基础上移除所有“xxx赞同了xx”，并隐藏“还有 x 个 xxx 的动态被收起”入口及其空卡片。

## 安装

需要浏览器装有 Tampermonkey 或 Violentmonkey 插件。

[安装 Pure Zhihu (Github)](https://raw.githubusercontent.com/squarezhong/pure-zhihu/main/pure-zhihu.user.js)

## 规则边界

- 严格模式仅在 `/follow` 关注流过滤来源行标明“赞同了回答/文章/想法/视频”的动态及折叠动态入口；混合分组中的正常动态仍保留。
- 搜索结果、回答正文、评论和个人主页不会因为提到这些词而被过滤。
- 搜索框仅清理热词提示，保留搜索关键词及浏览器恢复的输入。
- 顶栏频道规则不影响搜索分类、个人主页标签和通知/私信等操作。
- 脚本匹配 `zhihu.com` 及所有子域名（包括 `www.zhihu.com`、`zhuanlan.zhihu.com`）；首页跳转和严格模式的关注流过滤仅作用于 `www.zhihu.com`。
